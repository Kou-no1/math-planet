## 変更点

### 1. アプリ名とアイコン

作業ブランチのtitleとmanifestは既に「けいさんのほし」だった。一方、公開URLを読取り確認したHTMLは `title=kukucchi`、faviconは `/math-planet/favicon.svg`（旧Viteアイコン）、manifestとSWは404だった。したがって旧名の原因をキャッシュだけと断定せず、未反映の公開版とソースを区別した。本番にはデプロイしていない。

- title、application-name、apple-mobile-web-app-title、manifest name/short_name、初回導入の見出しを「けいさんのほし」に揃えた。
- favicon、manifest PNG、Apple PNG、初回導入のマークは同じオリジナルくくっち号。`APP_ICONS` で参照を管理し、SVGのtitleも正式名にした。
- キャッシュ上の古い絵と区別するため、参照するアイコンを版付きファイル名へ変更した。旧 `public/favicon.svg` も互換用に同じSVGを生成する。
- キャラクター名「くくっち」、内部package名、CSS・保存キー等の識別子はアプリ表示名と区別して維持した。
- base、manifest id/start_url/scope、SW scopeは `/math-planet/` のまま。公開URL・ドメイン・保存領域を変更していない。

| アイコン | `/math-planet/` 配下の参照 | 確認 |

### 2. おぼえる画面の枠・タブ

画面と開始カードの固定高さ、残り高を割り当てる内部グリッド、最小幅0のタブ列が重なり、選択欄を圧縮する構造だった。既存の小さい画面向け上書きだけに頼らず、おぼえる開始画面を内容に応じた高さへ変更した。

- 画面はmin-heightを維持して高さauto、カードも高さauto。長い内容はページを縦スクロールし、隠して解決しない。
- 上部、選択欄、スタートの順序と同じ左右余白を維持。見出しの「れんしゅう」は単語単位で改行し、末尾の1文字だけが次の行に出ないようにした。
- 計算欄を全幅にし、九九・たしざん・わりざん・平方数・円周率を最小幅96pxのグリッドで折り返す。ボタン高44px以上。
- スマホでは段／エリア、順番、答え方を1列に積む。パネル同士、ボタンと枠、スタートと選択欄が重ならないことをブラウザの実測で確認した。
- 問題生成・解答方式・順番の挙動は変更していない。たし・ひきの星専用画面に他演算の切替ボタンを追加していない。

### 3. モードカードの説明

全6星のあそぶ・おぼえる・スピード（低学年ではすぴーど）に説明を追加した。かけざんのあそぶはモンスターバトル、他星のあそぶはロケットという実際の導線に合わせた。たし・ひきの説明は漢字を使っていない。

かけざんの例:

- あそぶ: もんすたーとたたかいながら、九九をたのしくくりかえそう。
- おぼえる: だんをえらんで、ひんとをみながらじっくりれんしゅう。
- スピード: 30びょうからちゃれんじ。はやさとおぼえたことをたしかめよう。

アイコン・見出し・短いラベル・説明・すたーとを整理し、カードは固定高ではなくmin-heightと内容で伸びる。明るいカード背景には暗い文字を使い、説明が薄く見えないようにした。既存のモードへのリンク・報酬・学習内容は維持した。
