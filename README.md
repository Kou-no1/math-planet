# けいさんのほし（くくっち）

計算を遊びながら練習する、子ども向けのWebアプリです。バックエンドを使わず、進捗・コイン・経験値・称号・問題別成績を端末の `localStorage` に保存します。

## 主な機能

- 初回設定: よびな、アイコン、学習レベル、音設定
- ホーム: たし・ひき・かけ・わり・小数・分数の星選択。星のメニューにくくっち号、今日のミッション、にがて問題
- おぼえるモード: 段選択、4択、数字入力、まとまり表示、数直線、たし算、九九読み
- スピードモード: 30秒チャレンジ、スコア、コンボ
- リザルト: 正解数、正答率、平均回答時間、コイン、経験値、自己ベスト、称号
- 設定: 効果音、読み上げ、アニメーション軽減、JSONバックアップ・ひきつぎ

## GitHub Pages公開

`src/pwa/config.ts` の `APP_BASE` を `vite.config.ts` のbase、manifest、SW登録で共有し、`/math-planet/` を維持しています。公開URLは `https://manabitane.jp/math-planet/` です。今回のPWA対応では本番デプロイ・ドメイン・DNS/CNAMEの変更を行いません。

```bash
npm run build
```

生成物は `dist/` に出力されます。ルーティングは `HashRouter` のため、GitHub Pages上でのリロードや直リンクでも404になりにくい構成です。

## セーブデータ仕様

セーブデータは `version` を持つJSONです。主な内容は以下です。

- `player`: よびな、アイコン、学習レベル、レベル、経験値、コイン、称号
- `settings`: 効果音、読み上げ、アニメーション軽減
- `progress`: 問題別成績、履歴、自己ベスト、ミッション、所持アイテム

設定画面から「データをほぞんする」でJSONをダウンロードできます。ファイル保存が難しい端末では、表示されたJSONテキストをコピーできます。「データをひきつぐ」ではJSONファイルまたは貼り付けテキストから復元します。復元時はマイグレーション処理を通します。

## ホーム画面・オフライン

追加しなくてもブラウザで遊べます。ホームまたは設定の「ホーム画面に追加」から手順を確認できます。初回設定や学習中に追加ダイアログを自動表示しません。練習を一回完了してホームへ戻った後だけ小さな案内を出し、「今はしない」で7日間抑制します。保存拒否時も同じセッションでは再表示しません。

- Android/PC: ブラウザの `beforeinstallprompt` が届いた場合のみ追加ボタンを表示します。未対応・未発火時はブラウザのメニューからの追加方法を案内します。
- iPhone/iPad: Safariの「共有 → ホーム画面に追加 → 追加」。表示される場合は「ウェブアプリとして開く」をオンにします。メニューの位置はOSで異なります。
- SNS内/不明なブラウザ: アプリ開始URLをコピーしてSafari/Chrome等へ貼り付けます。通常リンクで外部ブラウザへ必ず移れるとは保証しません。
- 更新: ホームで明示的に「ほぞんして更新」を押したときだけ保存して再読み込みします。別のアプリタブが一つでもある場合、通信で状態を確認できない場合、保存に失敗した場合は止めます。他のタブは再読み込みしません。
- オフライン: オンラインで準備ができた後の起動・ホーム・基本の九九練習・採点・結果保存が対象です。初めての未キャッシュアクセスは通信が必要です。キャッシュが削除された場合や端末の音声が利用できない場合があります。

JS/CSSの依存グラフ（遅延読み込みを含む）と小さなアイコンを事前取得します。全画像・動画は対象にしません。実行時の画像キャッシュは同一オリジンかつSWスコープ内、40件・7日までです。実際の対象一覧・容量はビルド後の `dist/pwa-cache-report.json`、確認結果は [PWA_TEST_REPORT](docs/PWA_TEST_REPORT.md) を参照してください。

HTTPSまたはlocalhostで `npm run build` → `npm run preview` を使用してください。LANの通常HTTPはSWを利用できないことがあるため、本番相当の判定には使いません。`scripts/verify-pwa.mjs` は隔離したブラウザとローカルproduction配信で、オフライン・2版の更新・保存拒否・複数タブ・モバイルを試験します。Playwrightを利用できる環境では `PLAYWRIGHT_MODULE` にモジュールのパスを指定できます。

```powershell
npm run build
node scripts/verify-pwa.mjs
```

試験では一時ディレクトリに旧/新版の生成物・スクリーンショット・JSON結果を保存します。更新試験用に `dist` を再ビルドするため、試験後は `npm run build` で通常ビルドを作り直してください。本番公開は行いません。

## 記録を守る

保存キー `kukucchi-save-v1`、移行前バックアップ `kukucchi-save-before-migration`、SaveData v15は変更していません。追加案内の設定は別キー `keisan-no-hoshi-pwa-install-v1` です。壊れたJSON・将来版・読み込み拒否では元の記録を自動上書きしません。別タブが書いた新しい記録も古いタブから上書きせず警告します。

保存できない場合もメモリ上の記録を保持し、警告からファイル保存・コピー・復元へ進めます。復元は形式・版を検証してから確認し、直前の原文を `kukucchi-save-before-restore` に退避します。保存失敗時には元のデータを保持します。バックアップは先生コードなしで利用できます。

保護者への案内: **記録は端末・ブラウザごとです。別のブラウザやホーム画面アプリへ自動で移るとは限りません。削除・機種変更・移動の前に「せってい → データ」でJSONを保存し、移動先でひきついでください。** サイトデータの削除、OSの容量整理、プライベートモード等による消失を防ぐ保証はできません。同一オリジンのパス変更だけで必ず保存領域が別になる、という意味ではありません。

通知、会員登録、クラウド同期、広告・解析、児童データの外部送信は追加していません。iPhone/Androidの実機追加・OSキーボード・safe-area・翌日起動は別途確認が必要です。
